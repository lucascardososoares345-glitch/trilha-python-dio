## Como explorar

Com Python 3 instalado:

```bash
git clone https://github.com/lucascardososoares345-glitch/trilha-python-dio.git
cd trilha-python-dio
python "00 - Fundamentos/primeiro_programa.py"
```

Os exemplos introdutórios podem ser executados individualmente. Os módulos de frameworks e banco de dados podem exigir dependências e configurações específicas.
